# 🖼️ Images – Prep2Hire Frontend

This folder contains the visual assets used throughout the Prep2Hire frontend.

## 📌 Assets

The folder may contain:

* 🤖 AI interviewer avatar
* 🏢 Company logos
* 🎨 UI graphics
* 👤 Profile images
* 🖼️ Background images
* 🔹 Icons
* 📊 Dashboard illustrations
* 🎤 Interview-related graphics

## 📁 Example Structure

```text
images/
├── logo/
├── profile/
├── avatars/
├── icons/
├── backgrounds/
└── ...
```

These assets are used by the HTML and CSS files to create the visual appearance of the Prep2Hire platform.

> Only project-related assets should be stored in this folder. Avoid uploading unnecessary personal or system files.
